# Telecom Customer Churn Analysis

This is a practice project for analyzing and predicting customer churn using a telecom dataset. The goal is to explore the data, create new features, and test different modeling approaches.

## Dataset
You can download the dataset from [Dataset Link](https://www.kaggle.com/datasets/mnassrib/telecom-churn-datasets)

## Description
The project includes:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Visualization of customer behavior
- Basic churn prediction models
